# Sporturi Populare 🏆

## Descriere

Sporturi Populare este o aplicație web creată pentru prezentarea celor mai cunoscute sporturi practicate la nivel mondial. Website-ul oferă informații despre diferite sporturi, imagini reprezentative și scurte descrieri despre istoria acestora și jucători celebri.
Proiectul are un design modern și o interfață simplă, ușor de utilizat.

## Funcționalități

🏠 Pagină principală cu meniu de navigare

⚽ Secțiune dedicată fotbalului

🎾 Secțiune dedicată tenisului

🏀 Secțiune dedicată baschetului

🏐 Secțiune dedicată voleiului

🖼️ Imagini reprezentative pentru fiecare sport

📖 Informații despre istoria sporturilor

⭐ Prezentarea unor jucători de referință

## Despre sporturi

⚽ Fotbal

Fotbalul este cel mai popular sport din lume și este practicat de milioane de oameni. Competiții importante precum UEFA Champions League și Cupa Mondială atrag anual milioane de spectatori.

🎾 Tenis

Tenisul este un sport individual foarte apreciat la nivel internațional. Turnee precum Wimbledon, Roland Garros sau US Open sunt urmărite de fani din întreaga lume.

🏀 Baschet

Baschetul a fost inventat în anul 1891 de James Naismith și a devenit unul dintre cele mai populare sporturi de echipă. NBA este cea mai cunoscută ligă profesionistă de baschet.

🏐 Volei

Voleiul este un sport de echipă rapid și dinamic, practicat atât în sală, cât și pe plajă. Este foarte popular în competițiile internaționale și olimpice.
